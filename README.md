## 🚀 Featured Projects

### 🤖 [Mr. Analyst: AI Data Analysis Assistant](https://github.com/himanshurm0703/MR.Analyst)
Upload a CSV or PDF and ask questions in plain English.
- **PDF → RAG:** text is chunked, stored in **ChromaDB**, and the most relevant context goes to a **Groq LLM**
- **CSV → SQL:** the LLM writes a SQL query, **DuckDB** runs it read-only, and the LLM explains the result
- Wrapped in a **Streamlit** interface

**Impact:** anyone can explore a dataset or document by asking questions instead of searching manually.
`Python` `Streamlit` `Groq` `ChromaDB` `RAG` `LangChain` `Pandas`

---

### 🛒 [Brazilian E-Commerce Analysis](https://github.com/himanshurm0703/Brazilian-Ecommerce-Analysis)
Analysed **100K+ orders** to understand sales, seller efficiency, customer behaviour and delivery performance.
- Cleaned and transformed multi-table data with **Python and SQL Server**
- Designed a **star schema** for reporting
- Built a **Power BI dashboard** tracking KPIs across sales, sellers, customers and logistics

**Impact:** one dashboard for sales, seller, customer and delivery performance together.
`Python` `SQL Server` `Power BI` `Star Schema`

### 🍕 [Pizza Sales Dashboard](https://github.com/himanshurm0703/Pizza-Sales-Analysis-)
Interactive Power BI dashboard on **48K+ order line items**, with a custom date table and DAX measures for revenue, orders, pizzas sold and average order value.
- **Large pizzas bring in about 46% of revenue**, and Classic is the top category
- Orders **peak at lunch (12–1 PM) and on Fridays**

**Impact:** stock and promote Large pizzas first, and add staff at lunch and on Fridays.
`Power BI` `DAX` `Data Modeling`
